# SI React Template

Vite, React, TypeScript, Ant Design으로 만드는 SI 프로젝트용 기본 템플릿입니다. 작은 기능을 구현하고 이해·검증하며, 백엔드 없이 시연할 수 있는 포트폴리오로 발전시키고 있습니다.

현재는 공통 Top / Left / Content, 5개 테마 선택, light / dark 모드 전환, 화면 이동과 사용자 초기 25건의 목록·이름 및 활성 여부 검색·초기화·페이지 이동·등록·수정·일괄 삭제가 구현되어 있습니다. Top 오른쪽에서 Classic Blue, Soft Green, Modern Purple, Minimal Mono, Warm Orange를 선택하며 전체 색상과 모서리 형태가 바뀝니다. 옆 아이콘 버튼으로 light / dark를 전환합니다. 테마와 모드는 화면 이동 시 유지되고 새로고침하면 Classic Blue·light로 돌아갑니다. 이름은 검색 버튼이나 Enter로 부분 검색하며 앞뒤 공백과 영문 대소문자를 무시합니다. 활성 여부는 전체·Y·N 중 선택합니다. 입력만으로 목록은 바뀌지 않으며 검색·초기화 시 1페이지로 돌아갑니다. 총 건수를 표시하고 한 페이지에 10명씩 보여 줍니다. 결과가 없으면 빈 결과 안내를 표시합니다. 체크박스로 현재 페이지의 여러 행을 선택하거나 헤더 체크박스로 현재 페이지 전체를 선택할 수 있습니다. 페이지를 이동하면 선택은 초기화됩니다. 삭제 확인 팝업에서 확인하면 선택된 사용자가 모의 데이터에서 실제로 제거되고 목록을 다시 조회합니다. 마지막 페이지가 없어지면 유효한 페이지로 이동하며, 전체 삭제 후에는 1페이지의 빈 결과를 표시합니다. 실제 HTTP API 연동은 아직 없습니다. 실제 브라우저 검증 현황은 [개발·학습 계획](./docs/learning-plan.md)에서 관리합니다.

사용자 목록은 메모리 기반 모의 API로 약 400ms 후 조회합니다. 조회 중에는 대기 안내를 표시하고 이전 목록·총 건수·페이지 버튼을 숨깁니다. 조회 실패는 빈 결과와 구분하여 안내합니다. 실패 후 검색 버튼이나 Enter로 현재 검색 입력을 적용해 1페이지부터 다시 조회할 수 있습니다. 등록 버튼은 총 건수 줄 오른쪽 끝에서 이름·이메일·부서·활성 여부 입력 모달을 엽니다. 취소 후 재열기에는 빈 입력과 활성 Y로 초기화합니다. 저장 버튼은 필수값·이메일 형식을 검증하고 앞뒤 공백을 정리합니다. 모의 API도 필수값·형식·Y/N과 공백·대소문자를 무시한 중복 이메일을 검사합니다. 저장 중 입력·반복 제출·닫기를 막으며 실패 시 입력을 유지합니다. 성공 시 모달을 닫고 조건을 유지한 1페이지를 다시 조회합니다. 새 사용자는 목록 앞에 추가되며 조건에 맞지 않으면 표시되지 않습니다. 등록 성공 후 조회 실패는 별도로 안내하고 검색으로 조회만 재시도합니다. 데이터는 메뉴 이동 시 유지되지만 새로고침하면 초기 25건으로 돌아갑니다. 다른 탭과 공유하지 않습니다.

조회 오류를 재현하려면 `src/features/users/api/userApi.ts`의 `SHOULD_FAIL_USER_LIST`를 `true`로 바꾸고 검색하거나 화면을 새로고침합니다. 약 400ms 후 오류 안내가 표시됩니다. `true`인 동안 다시 검색해도 실패합니다. 확인 후 `false`로 되돌리고 검색으로 정상 조회를 확인합니다. 소스 수정에 따른 개발 서버 갱신은 화면 상태를 초기화할 수 있습니다. 기본값은 `false`이며, 이 설정은 모의 조회만 실패시킵니다.

사용자 ID는 등록 시 직접 입력하는 필수값입니다. 앞뒤 공백을 제거해 저장하고 대소문자를 무시하여 중복을 검사합니다. 특정 사번 형식이나 통합 로그인 규칙은 기본 템플릿에 강제하지 않으며, 해당 조직의 요구에 맞춰 별도로 구현합니다.

등록 성공·조회 실패 메시지는 확인 버튼으로 닫는 Ant Design 메시지 팝업으로 표시합니다. 등록 성공 메시지의 확인을 누른 뒤 목록을 다시 조회합니다. 조회 실패 팝업을 닫은 뒤 검색으로 다시 조회할 수 있습니다. 등록 모달 안의 저장 실패 메시지는 입력과 함께 유지됩니다. 다른 화면에서도 `src/utils/appAlert.ts`의 `appAlert`를 import해 `appAlert.success("메시지")` 또는 `appAlert.error("메시지")`로 표시합니다. 확인 후 다음 작업을 진행하려면 `await appAlert.success("메시지")`로 호출합니다. AppAlertSetup이 앱에서 한 번 연결하므로 화면별 훅 호출이나 팝업 설정은 필요 없습니다. 연결이 완료된 후 이벤트 처리 함수나 비동기 처리에서 호출하며, 모듈 로딩 시점이나 렌더링 중에는 호출하지 않습니다.

## 시작하기

사용자 목록의 작업 열에서 수정 버튼을 누르면 선택한 사용자의 정보를 같은 모달에 표시합니다. 수정 ID는 읽기 전용이며 다른 입력값을 변경·검증하고 저장할 수 있습니다. 자기 이메일은 유지할 수 있지만 다른 사용자의 이메일은 중복으로 거부합니다. 저장 실패 시 입력을 유지하고, 성공 팝업 확인 후 조건을 유지한 1페이지를 다시 조회합니다. 수정 완료 후 조회 실패도 구분해 안내하며 검색으로 목록만 다시 조회합니다. 취소 후 등록을 열면 빈 입력과 활성 Y로 초기화됩니다.

사용자 목록은 **AG Grid Community**로 표시합니다. Ant Design은 레이아웃·버튼·입력 등 기본 UI에 사용합니다. 향후에도 유료 버전으로 전환하지 않으며, Community에서 제공하지 않는 추가 기능은 필요할 때 직접 개발합니다.

Node.js 24와 npm이 필요합니다. 프로젝트 루트에서 실행하세요.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소로 접속하세요. 서버 종료는 `Ctrl+C`입니다.
Windows PowerShell에서는 `npm` 대신 `npm.cmd`를 사용할 수 있습니다.
